# 磁力牛顿摆参数对比工具

启动方式：

双击 `启动参数对比工具.bat`，或在当前文件夹运行：

```powershell
python 05_code\parameter_compare_gui.py
```

## 能做什么

这个工具用于把实验数据和当前理论模型放在同一界面中对比。左侧可以修改参数，右侧会显示：

- 时域对比：实验为实线，模拟为虚线
- 频域对比：实验为实线，模拟为虚线
- 平均 RMS 包络：用于看阻尼和静止快慢
- 主峰频率误差表：用于判断耦合模态是否对上

## 建议调参顺序

1. 先固定磁力缩放为 `0.5`，不要为了单组数据随便改。
2. 改轴间距，看主频结构是否按趋势变化。
3. 改有效摆长，看基础频率整体平移。
4. 改阻尼 `c1/c2`，看 RMS 包络衰减是否接近实验。
5. 改释放角或直接初始角，看时域相位和能量交换是否更接近。

## 判断标准

不建议追求每一秒轨迹完全重合，因为磁力牛顿摆对初始条件很敏感。更合理的判断顺序是：

1. 主频是否接近
2. 高频模态是否出现
3. RMS 包络衰减是否接近
4. 时域能量交换顺序是否相似

若主频能对上，说明耦合模态解释较好；若 RMS 包络能对上，说明阻尼解释较好；若时域逐点也能对上，那属于额外加分，不是当前模型必须达到的最低要求。
