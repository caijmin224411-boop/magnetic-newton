# 磁力牛顿摆理论应用总结

## 一、我们现在的理论到底在解释什么

磁力牛顿摆不是普通牛顿摆，也不是五个彼此独立的单摆。它的核心是：

1. 每个摆本身有重力回复力矩。
2. 相邻磁体之间有磁力，磁力会转化成对摆的磁力矩。
3. 阻尼会让能量逐渐耗散。
4. 多个摆之间通过磁耦合交换能量，因此会出现多个频率模态。

所以模型要解释的不是“某一个摆的频率”，而是：

- 基础单摆频率来自摆长；
- 额外频率峰来自磁耦合；
- 轴间距改变会改变磁耦合强度；
- 时域中的不规则性来自非线性磁力和多模态叠加；
- 衰减快慢主要由阻尼和耦合维持振动的能力共同决定。

## 二、基础运动方程

第 `i` 个摆的运动方程写成：

```math
I_i\ddot{\theta}_i
=
\tau_{g,i}
\tau_{m,i}
\tau_{d,i}
```

其中：

```math
I_i=m_iL_i^2
```

重力力矩：

```math
\tau_{g,i}=-m_i g L_i\sin\theta_i
```

阻尼力矩：

```math
\tau_{d,i}=-c_{1,i}\dot{\theta}_i-c_{2,i}\dot{\theta}_i|\dot{\theta}_i|
```

磁力矩：

```math
\tau_{m,i}=\sum_{j\ne i}\tau_{ij}
```

当前模型主要考虑相邻摆：

```math
j=i-1,\ i+1
```

后续更精确时，应加入非相邻项：

```math
j=1,2,3,4,5,\quad j\ne i
```

## 三、磁耦合强度怎么理解

磁耦合强度不是简单等于磁场强度 `70 mT`。更准确地说，它是磁力矩对摆角变化的敏感程度。

在平衡位置附近，可以把磁力矩线性化：

```math
\tau_{ij}\approx -k_m(\theta_i-\theta_j)
```

这里的 `k_m` 就是等效磁耦合刚度。

它和重力回复力矩相比，可以定义无量纲参数：

```math
\eta=\frac{k_m}{mgL}
```

- `eta << 1`：弱耦合，接近独立单摆；
- `eta ~ 1`：强耦合，模态分裂明显；
- `eta > 1`：磁力主导，非线性和复杂运动明显。

轴间距越小，磁力越强，`k_m` 越大；轴间距拉开后，磁耦合变弱，系统更接近独立单摆，所以可见静止更快。

## 四、初始释放为什么影响频谱

单个小角度单摆的频率主要由摆长决定：

```math
f_0=\frac{1}{2\pi}\sqrt{\frac{g}{L}}
```

但磁力牛顿摆有多个耦合模态：

```math
f_1,\ f_2,\ f_3,\ldots
```

释放方式不随便改变这些固有频率，但会决定每个模态被激发得多强：

```math
\theta(t)=
A_1\phi_1\cos(2\pi f_1t+\varphi_1)
A_2\phi_2\cos(2\pi f_2t+\varphi_2)
\cdots
```

因此初始释放主要影响：

- 哪些频率峰更强；
- 时域相位；
- 能量交换顺序；
- 大振幅非线性下的轻微频率偏移。

## 五、目前模型和实验的真实关系

### 3 cm 间距

实验主峰：

```text
1.396 Hz, 2.188 Hz, 3.274 Hz
```

统一磁力缩放 `0.5` 下模型：

```text
1.417 Hz, 2.333 Hz, 3.550 Hz
```

低频模态较好，高频偏高，说明强耦合下模型偏硬。

### 5 cm 间距

实验主峰：

```text
1.387 Hz, 1.846 Hz, 2.543 Hz
```

统一磁力缩放 `0.5` 下模型：

```text
1.433 Hz, 1.883 Hz, 2.517 Hz
```

前三个主峰较接近，说明弱耦合情况下模型更可靠。

## 六、实话实说的结论

当前模型能解释：

- 摆长决定基础频率；
- 轴间距改变会改变耦合模态；
- 拉开轴间距后磁耦合变弱，振动衰减更快；
- 实验频谱中出现多个主峰；
- 时域不是简单的逐个碰撞传递，而是多摆能量交换。

当前模型还不能完全解释：

- 静态平衡角和动态频率用同一参数完美同时拟合；
- 时域轨迹逐点重合；
- 个别高频峰，比如 5 cm 实验中的 `3.37 Hz`。

这说明模型是半定量有效模型，不是最终精确模型。

## 七、下一步让理论更精准的方法

优先级如下：

1. 五个摆分别单摆标定，得到 `L_i, c1_i, c2_i`。
2. 测 `3 cm, 4 cm, 5 cm, 6 cm` 的静态平衡角，用来约束磁力矩。
3. 每个间距重复释放 3 次，比较主频、RMS 衰减、峰间隔变异系数。
4. 模型中加入初始速度。
5. 模型中加入非相邻磁力作用。
6. 保持统一磁力缩放，不要为了每组实验单独调磁力。

最关键的研究思想是：

> 单摆定摆长和阻尼，静态平衡定磁力矩，动态实验验证频率、衰减和能量交换趋势。
